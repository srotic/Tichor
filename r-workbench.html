Write and run R in your browser

An RStudio-inspired workspace with an R editor and console, powered by webR (R compiled to WebAssembly). This is not the official RStudio IDE. R executes locally on your device.

Compatibility: webR requires browser support for WebAssembly and appropriate security headers. First load may be large. Some CRAN/Bioconductor packages, graphics devices and file operations may not work. No paid AI API is used.
