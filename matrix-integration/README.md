# Matrix migration (staging only; not activated)
SDK candidate: matrix-js-sdk 45.1.0 (Apache-2.0). Review current advisories, pin transitive dependencies with a committed lockfile, and build/self-host browser WASM assets before activation. No remote script import.
Homeserver: https://matrix.tichor.com — proposed, not provisioned. Use a supported Synapse or managed Matrix deployment with TLS, private registration, appropriate federation policy, backups, monitoring, rate limits and a maintained authentication integration. Cloudflare Pages alone cannot host a persistent Synapse service.
Authentication: implement audited server-side identity mapping between Supabase account UUID and Matrix user ID. Authenticate via supported OIDC/SSO or account provisioning; never derive passwords from user IDs or tokens. Never expose admin tokens or issue access tokens from browser code. Verify account binding before enabling transport.
Crypto: initialize Rust Crypto per device with persistent isolated IndexedDB and exclusive tab locking. Implement secret storage, cross-signing, interactive verification, recovery, key backup and policy for unverified devices before activation. The transport adapter alone does not enforce these policies.
Room migration: create new private encrypted rooms and map only approved contacts; enforce membership, history visibility, invitations, device trust and no plaintext fallback. Do not automatically upload existing messages into Matrix. Keep old history explicitly labelled and separate.
Media: use documented Matrix encrypted attachment flow, and independently validate call encryption (MatrixRTC is separate). Disable unprotected routes when protected mode is mandatory.
Acceptance: test real homeserver with two accounts and multiple devices, offline delivery, recovery, revoked devices, cross-signing, membership changes, encrypted event inspection, browser compatibility, dependency security, and external integration review. Do not claim full E2EE before sign-off.
Existing beta and V3 deployment are unchanged. No production chat import of transport.mjs.
